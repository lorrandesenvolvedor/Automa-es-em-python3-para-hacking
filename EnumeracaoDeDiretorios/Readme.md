# Enumerador de Diretórios - Python
![enumeracao](./enumeracao.png)

**Para que esse exemplo serve ?**

_um exemplo bem simples de como criar uma automação em Python para listar diretórios de uma plataforma Web_

**Biblioteca necessária caso queira testar**

_pip install httpx_

**O'que eu preciso fazer para testar?**

Editar o arquivo (principal.py) adicinando nele o site desejado 
Editar o arquivo (diretorios.txt) adicionando nele a quantidade de Possíveis direotrios e arquivos que deseja que a automadao procure.


_Procure utilizar isso apenas como exemplo e criar uma versão melhorando, passando por firewalls, bloqueios do navegador por falta de headers etc... faça o seu melhor isso e apenas um exemplo educativo._
